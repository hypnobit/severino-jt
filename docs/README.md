# docs/

- **`prompt-triagem.md`** — protocolo de triagem de 5 passos. Especificação do domínio que o dossiê serve. É a referência quando `AGENTS.md` menciona "Passo 3", "Passo 5" etc.
- **`adaptar-outro-trt.md`** — como configurar a extensão para um TRT diferente da 8ª Região.
- **`permissoes.md`** — por que a extensão pede cada permissão do `manifest.json`.
- **`ferramentas/`** — documentação de cada ferramenta, uma página por arquivo.

Em caso de conflito, `AGENTS.md` é a referência.
